# AgenticThesis v1.1 Execution Record

Status: implemented on `main`; deterministic release gates passed

Product gate: **Every accepted authoritative company event is atomically preserved, deterministically routed against explicit thesis falsifiers, cited back to immutable source artifacts, and kept non-authoritative until Human Review.**

## P0 delivered

1. Source-neutral `source_id`, `source_date`, and `event_date` contracts on a clean schema.
2. One transactional event seam for artifacts, parse and fetch failures, Radar decisions, and run registration.
3. Replay-safe run IDs plus process-local source locks matching the in-process scheduler.
4. SEC amendment selection and deterministic linking by base form and reporting period.
5. SEC form-family coverage for periodic/current reports, proxies, insider and beneficial ownership, institutional holdings, and uncommon retained forms.
6. Native PDF extraction with exact page locators; encrypted, malformed, and image-only states; bounded opt-in OCR with concurrency one and no model download.
7. Versioned claim/falsifier Radar routing with a checked-in deterministic gold set.
8. Explicit issuer IR HTML/feed monitoring with relevant one-hop same-host documents, discovery-page provenance, content-replacement/link-removal events, and official transcript ingestion when text is published.
9. Artifact downloads forced to attachment with `application/octet-stream` and `X-Content-Type-Options: nosniff`.
10. Browser Radar Inbox plus SEC and IR configuration and manual sync.

## Release gates

- deterministic suite passes without network or model calls;
- every accepted PDF quote resolves to its stored artifact and page;
- replay creates zero duplicate Radar entries or runs;
- SEC amendments link to the original event when the reporting period is available;
- unchanged IR documents create no event; changed and removed documents remain observable;
- secondary sources cannot independently create an authoritative revision;
- README, README_ZH, public models, API version, and architecture assets agree.

## Deliberately deferred

- reliable secondary-news leads;
- cross-host IR links unless configured explicitly;
- headless browsing, generic crawling, anti-bot bypass, audio transcription;
- built-in OCR models;
- distributed scheduling, queues, provider SDKs, and Multi-Agent workflows.

Add any deferred item only after a real source or user case demonstrates that the current bounded path cannot represent it safely.
